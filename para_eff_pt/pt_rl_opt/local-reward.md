# 强化学习优化器 (RL-Scheduler) 细粒度奖励设计方案

## 1. 设计背景与核心理念

在多张量（Multi-Tensor）的动态优化调度中，如果所有参数组共享单一的全局奖励（Global Reward），系统将面临严重的**信用分配（Credit Assignment）问题**。局部表现差的参数组可能会“搭便车”享受全局 Loss 下降带来的正向反馈，导致 PPO Agent 无法精准定位并纠正局部的错误决策。

**核心约束原则：职责隔离**
在当前的 RL-Scheduler 架构中，张量更新的**实际方向由底层 AdamW 优化器（基于历史动量）决定，而 PPO Agent 仅负责决定学习率（即更新步长）**。
因此，局部奖励（Local Reward）的设计必须严格遵守以下原则：
1. **禁用动量信息**：动量具有历史滞后性，会污染 MDP（马尔可夫决策过程）对当前动作的即时反馈。
2. **聚焦瞬时几何特征**：局部奖励应当仅用于评估 PPO 设定的“步长”是否导致该参数组在当前的局部非凸曲面上发生了破坏性更新（如梯度爆炸、越过平滑区）。

## 2. 奖励函数解耦架构

将总体奖励拆分为全局牵引与局部护栏（Guardrails）：对于第 $i$ 个参数组，在第 $t$ 步的总奖励 $R_{total\_i, t}$ 定义为：

$$R_{total\_i, t} = R_{global, t} + R_{local\_i, t}$$

* **$R_{global, t}$ (全局奖励)**：负责大方向的牵引，沿用现有的性能收益（Loss 下降）、趋势收益与全局稳定性控制。
* **$R_{local\_i, t}$ (局部奖励)**：负责微观的细粒度约束，由更新幅度惩罚、瞬时梯度激增惩罚和动作震荡惩罚组成。

## 3. 局部奖励 (Local Reward) 设计细则

### 3.1 相对更新幅度惩罚 (Trust Ratio Penalty)
**目的**：防止 PPO 给出过大的学习率，导致单步参数更新量相对于原有参数信息过大，从而引发“灾难性遗忘”或特征破坏（思想借鉴自 LARS/LAMB 优化器）。

**指标定义**：计算参数更新的 L2 范数与参数自身 L2 范数的比值（Trust Ratio）。
$$TR_{i, t} = \frac{|| \Delta w_{i, t} ||}{|| w_{i, t} || + \epsilon}$$
由于 $\Delta w_{i, t}$ 直接受 PPO 输出的局部学习率缩放控制，该指标能最直观地反映动作的危险程度。

**奖励计算**：设定安全阈值 $\tau_{tr}$（例如 $0.005$ 或 $0.01$）。越界则给予线性或指数惩罚。
$$R_{trust\_i, t} = \begin{cases} 0, & \text{if } TR_{i, t} \le \tau_{tr} \\ -\lambda_{tr} \times (TR_{i, t} - \tau_{tr}), & \text{if } TR_{i, t} > \tau_{tr} \end{cases}$$

### 3.2 瞬时梯度激增惩罚 (Local Gradient Spike Penalty)
**目的**：当学习率设定过大时，参数容易跨越当前的平滑极小值区域，撞向损失函数曲面的高墙（Overshooting），这在微观上表现为瞬时梯度的剧烈飙升。

**指标定义**：利用相邻两步之间对数梯度范数的差值（即现有特征空间中的 `delta_gn`）。
$$\Delta GN_{i, t} = \log_{10}(||g_{i, t}|| + \epsilon) - \log_{10}(||g_{i, t-1}|| + \epsilon)$$

**奖励计算**：允许正常的梯度波动，但对异常激增进行二次方惩罚，以形成强烈的负向优势函数（Negative Advantage）。设定激增阈值 $\delta_{sp}$（例如 $0.5$，表示单步梯度膨胀约 3 倍）。
$$R_{spike\_i, t} = \begin{cases} 0, & \text{if } \Delta GN_{i, t} \le \delta_{sp} \\ -\lambda_{sp} \times (\Delta GN_{i, t} - \delta_{sp})^2, & \text{if } \Delta GN_{i, t} > \delta_{sp} \end{cases}$$

### 3.3 动作震荡惩罚 (Action Oscillation Penalty)
**目的**：即便局部曲面复杂，学习率的调度也应尽量保持平滑，避免 PPO Agent 出现高频的动作抖动。

**指标定义**：Agent 在相邻两步对同一参数组输出的学习率对数（或动作本身）的绝对差值。
$$O_{i, t} = |a_{i, t} - a_{i, t-1}|$$

**奖励计算**：直接作为正则项引入，充当动作空间的时间维度低通滤波器。
$$R_{osc\_i, t} = - \lambda_{osc} \times O_{i, t}$$
